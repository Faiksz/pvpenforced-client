# Pvpenforced Client

Official game client for **[Pvpenforced](https://pvpenforced.com)**, a free-to-play classic online RPG server on the 7.72 protocol, hosted in Sydney, Australia.

## Download (Windows)

**[Download the latest client](https://github.com/Faiksz/pvpenforced-client/releases/latest/download/pvpenforced-client.zip)**

1. Extract the zip anywhere.
2. Run `Pvpenforced/Pvpenforced_OpenGL.exe`.
3. Pick your world (Global or PvP Enforced) and log in. The client updates itself automatically before login.

Need an account? Create one at [pvpenforced.com](https://pvpenforced.com).
